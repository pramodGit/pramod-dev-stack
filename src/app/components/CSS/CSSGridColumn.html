In a n-column grid, there are total (n + 1) vertical lines.

The grid-column property dictates where an element starts, ends, or how many columns it spans across the grid.

It is a shorthand for grid-column-start and grid-column-end.

In CSS Grid, grid-column can work like a table's colspan.

If you have 4 columns:

display: grid; grid-template-columns: 1fr 1fr 1fr 1fr;

The grid lines look like:

| 1 | col1 | 2 | col2 | 3 | col3 | 4 | col4 | 5 |

Take the 2 center columns (columns 2 and 3)

grid-column: 2 / 4

This means:

  • Start at grid line 2
  • End at grid line 4

Result:

| col1 | [ item spans col2 + col3 ] | col4 |

Equivalent using span

grid-column: 2 / span 2;
Start at column 2 and span 2 columns.

Span one column

grid-column: 2;

Span two columns

grid-column: 2 / 4;

Span all four columns

grid-column: 1 / -1;
-1 means the last grid line.
