min(value1, value2) is a CSS function that chooses the smaller of two values.

width: min(70ch, 100%);

means:

Use 70ch, unless that's wider than 100% of the available space. In that case, use 100%.

Why use it?

Suppose you're styling article content:

  • On a large screen:
    • 70ch might be ~700px
    • 100% might be 1200px
    • Smaller value = 70ch
    • Result: readable line length
  • On a small phone:
    • 70ch might be ~700px
    • 100% might be 360px
    • Smaller value = 100%
    • Result: content doesn't overflow

Compared to max-width

These are often similar:

width: min(70ch, 100%);
width: 100%; max-width: 70ch;

Both keep the content from exceeding 70ch while allowing it to shrink on smaller screens.

In the grid example

grid-template-columns: 1fr min(70ch, 100%) 1fr;

This creates three columns:

| 1fr | content | 1fr |

where the center content column is:

  • at most 70ch wide
  • but can shrink to fit smaller screens

This is a modern way to create a centered reading column with flexible margins on both sides.
