Grid :: Repeat Auto-Fit MinMax Pattern

grid-template-columns: repeat(count, track-size);

1. grid-template-columns

Defines how many columns the grid should have and their widths. Creates 2 columns of 200px each.

grid-template-columns: 200px 200px;

For single-column layout

grid-template-columns: 1fr;

2. repeat()

Instead of writing columns manually:

grid-template-columns: 1fr 1fr 1fr;

We can write:

grid-template-columns: repeat(3, 1fr);

3. auto-fit

Grid automatically determines how many columns can fit in the available space.

grid-template-columns: repeat(auto-fit, minmax(250px, 1fr));

Container width = 1000px

250 + 250 + 250 + 250 = 1000

Result:


        +------+ +------+
        | Item | | Item |
        +------+ +------+

Grid automatically adjusts.

4. minmax(250px, 1fr)

minmax(MINIMUM_WIDTH, MAXIMUM_WIDTH)

Meaning:

  • Never shrink below 250px
  • Grow to fill available space
